# Changelog

## 1.0.0

- Visual schema designer for `*.kosmora.json` files
- Schema Designs view that lists every design in your workspace
- Get Started walkthrough with screenshots, on the VS Code Welcome page
- Exports: JSON Schema, MongoDB validators, Mongoose, TypeScript, Prisma, Pydantic, Markdown, Mermaid, DBML, SVG, PNG
- Works completely offline, with no database connection
